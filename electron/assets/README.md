# Icônes de l'application

Placez ici les icônes pour l'application :
- `icon.png` (512x512) - Icône principale
- `icon.ico` (Windows) - Icône pour Windows
- `icon.icns` (macOS) - Icône pour macOS

## Générer les icônes

Vous pouvez utiliser un service en ligne comme :
- https://www.icoconverter.com/
- https://convertio.co/png-ico/

Ou des outils CLI comme `electron-icon-builder`.
